nx-cugraph Final Release: RAPIDS 26.12

nx-cugraph, the GPU accelerated NetworkX backend, was deprecated in RAPIDS 26.12. RAPIDS 26.12 is its final release. nx-cugraph is not included in RAPIDS 27.02 or later. Nightly builds continue only for the 26.12 release line through its final release.

For supported GPU graph analytics, use cuGraph directly.

Existing nx-cugraph users should keep their environments on matching RAPIDS 26.12 packages. See the final-release installation guidance for version-pinned commands.
